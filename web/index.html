    How it's built

    1. Pi 4 + MCP2515 on the OBD-II port
    2. OBD-II polling over SocketCAN
    3. One CSV per drive
    4. Python analysis in a GitHub Action
    5. This page

    The car's gateway blocks passive listening, so the logger asks the engine for each value, with a small ISO-TP layer for multi-frame replies. Code, hardware notes and the full report are on GitHub.
